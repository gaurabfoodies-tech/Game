# Shadow Quest 3D

Original Godot 4.x code-only third-person adventure **prototype** for Android and desktop.

## Run
1. Download repository ZIP from GitHub (Code > Download ZIP).
2. Extract it.
3. Open Godot 4.x and import `project.godot`.
4. Run the main scene.

## Controls
- Desktop: arrow keys, Space jump, F sword attack, hold right mouse button and drag to orbit camera.
- Android: drag left side to move; drag right side to orbit camera; JUMP and ATTACK buttons.

## Missions
Collect 5 coins, defeat 3 enemies, reach ruins at north end of path.

## Limitations
Procedural placeholder models, no animations, no real imported 3D assets, no tested APK. Runtime validation has not been performed. This is a starting playable prototype, not a finished realistic game.
